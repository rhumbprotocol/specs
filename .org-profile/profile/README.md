# Rhumb Protocol&trade;

**An open protocol for AI-assisted workflow.**

Rhumb Protocol&trade; (RWP - Rhumb Workflow Protocol) defines the
plain-file contract for AI-assisted delivery: plans, intakes,
manifests, state, handoffs, schemas, and governance that survive across
tools, agents, and sessions.

[Visit rhumbprotocol.dev](https://rhumbprotocol.dev) | [Read the spec](https://github.com/rhumbprotocol/specs/blob/main/docs/PROTOCOL.md) | [Getting started](https://github.com/rhumbprotocol/specs/blob/main/docs/GETTING-STARTED.md)

---

## Why a protocol layer

AI workflow today is a private project format per tool. Plans, handoffs, and
state files are shaped by whichever assistant wrote them, and the audit trail
breaks the moment work crosses a tool boundary.

RWP standardizes the artifacts around complex work so a plan can move between
people, agents, vendors, and implementations without losing the audit trail.

- **Plain files, not a platform** - Markdown, YAML, JSON Schema. Adopt with any editor or CI system.
- **Vendor-neutral by design** - advisory, not enforcing. RWP recommends; it does not lock in.
- **Apache-2.0 licensed** - built for third-party implementations from day one.
- **Reference implementation, not vendor dependency** - YAKKL Meridian implements RWP, but the protocol stands alone.
